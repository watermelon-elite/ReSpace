# Publish only seamless finished rooms

The user accepts waiting for reconstruction and requires a finished product rather than intermediate room previews. Generate plausible unseen surfaces for seamless use without estimated-region labels or overlays; keep source and processing records internally for reproducibility. Publication must therefore be gated on completion, background consistency, and usable editing assets, while failed or partial reconstruction artifacts remain internal and the last finished design stays available during subsequent processing. This favors coherent walkthroughs over early partial visualization. The later accepted pilot budget is $5 per room with a 30-minute processing target; neither cost nor speed has been benchmarked.
